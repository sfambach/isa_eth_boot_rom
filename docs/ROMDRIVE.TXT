ISA ETH Boot ROM - ROM drive
============================

This read-only drive comes from the boot flash of the network card.

Start the network (AUTOEXEC.BAT), with the drive letter of this drive:

    SET MTCPCFG=C:\MTCP.CFG
    D:\NETSTART

MTCPCFG must name a file on a writable drive; NETSTART writes the network
lines into it and keeps all other lines. Then use the mTCP programs from
this drive, e.g. D:\PING, D:\HTGET, D:\FTP.

Settings (stored in the flash of the card):

    NETCFG                         show card and settings
    NETCFG DHCP                    address by DHCP
    NETCFG STATIC ip mask gw dns   fixed address
    NETCFG NAME hostname
    NETCFG FLASH image.bin         update the ROM, settings are kept
